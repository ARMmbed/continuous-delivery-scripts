Language and project plugin guides

CDS uses the project's PROGRAMMING_LANGUAGE setting to select a plugin. Start with the landing page for your plugin, then follow its topic guides:

  • Basic — Git-based releases without a language-specific package.
  • CI — Releases for CI configuration projects.
  • Docker — Docker project integration.
  • GitHub Actions — CI workflow releases with GitHub integration.
  • Go — Go releases, modules and dependency preparation.
  • No-op — Projects that do not need language-specific steps.
  • Python — Python package releases and dependency metadata.

The general release guide describes the shared CDS workflow. Add future plugin-specific topic guides as Markdown files under guides/ and link them from the appropriate plugin landing page; the documentation generator publishes these pages alongside the API reference.
