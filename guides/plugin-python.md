# Python plugin guides

Select `PROGRAMMING_LANGUAGE = "python"` for Python projects. The plugin uses
wheel and Twine for package releases, pdoc for API documentation and installed
distribution metadata for dependency licence reporting.

- [Automate releases](automating-releases.md) — The shared release workflow.
- [Generate code documentation](generating-code-documentation.md) — Produce Python API pages.
- [Assess dependency licences](assessing-dependency-licences.md) — Review installed dependency metadata.
- [Python plugin reference](https://github.com/ARMmbed/continuous-delivery-scripts/blob/main/continuous_delivery_scripts/plugins/PYTHON.MD) — Packaging credentials and audit details.
