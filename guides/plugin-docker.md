# Docker plugin guides

Select `PROGRAMMING_LANGUAGE = "docker"` for a Docker project. The current
plugin supports CDS release orchestration; Docker image build and publication
are not implemented by this plugin.

- [Automate releases](automating-releases.md) — The shared release workflow.
- [Docker plugin API](https://armmbed.github.io/continuous-delivery-scripts/plugins/docker.html) — Current plugin capabilities.
