# Go plugin guides

Select `PROGRAMMING_LANGUAGE = "golang"` for a Go project. The plugin uses
GoReleaser for packaging and supports Go module discovery, documentation and
dependency licence reporting.

- [Go multi-module projects](go-multi-module.md) — Split a project into modules and prepare coordinated internal dependency versions for one CDS release.
- [Automate releases](automating-releases.md) — The shared release workflow.
- [Generate code documentation](generating-code-documentation.md) — Generate Go API pages with doc2go.
- [Generate an SPDX SBOM](generating-an-spdx-sbom.md) — Report Go dependency metadata.
- [Go plugin reference](https://github.com/ARMmbed/continuous-delivery-scripts/blob/main/continuous_delivery_scripts/plugins/GOLAND.MD) — Go-specific prerequisites and configuration.
